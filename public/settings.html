+ Connecter un compte Google

Le nom apparaît dans le champ « De » des emails du compte ; la signature (variables acceptées) s'insère à l'emplacement de {{signature}} dans les étapes de vos campagnes. Warm-up : montée en charge automatique — un compte démarre à 10 emails/jour puis gagne +5/semaine jusqu'à son quota (recommandé pour les boîtes récentes ; décochez pour une boîte déjà rodée). Si un compte se décoche tout seul (colonne Actif), son accès Google a été révoqué : reconnectez la même adresse pour le réactiver.

Comptes LinkedIn

CompteExécutionInvitationsMessagesEn fileContactsPlafonds / jourActif

Chaque compte LinkedIn a son extension Chrome (dossier extension/), dans le Chrome où ce compte est connecté. Collez le jeton du compte dans le popup de l'extension. Quotas, délais et pauses sont propres à chaque compte ; un contact reste au compte qui l'a abordé en premier (un message ne part que d'un compte connecté au destinataire). Plafonds vides = valeurs par défaut du serveur ; le warm-up les atteint progressivement.
Navigateur serveur (plus besoin de laisser Chrome ouvert) : dans le popup de l'extension, cliquez « Confier ce compte au serveur » — la session LinkedIn part chiffrée, puis renseignez ici un proxy résidentiel/ISP fixe propre au compte, situé dans la région de son propriétaire (sans proxy, le serveur ne lance rien : une IP de datacenter fait restreindre le compte). Ne vous déconnectez pas de LinkedIn ensuite : cela couperait aussi la session du serveur. Les réponses reçues sur LinkedIn sont détectées (lecture de la messagerie toutes les ~20 min) et arrêtent la séquence, emails compris.

Mode serveur indisponible : LI_SECRET_KEY et LI_RUNNER_SECRET doivent être définis dans le .env du serveur.

Délivrabilité & intégrations

Ces réglages se modifient dans le fichier .env (puis redémarrer le serveur). Voir .env.example.
